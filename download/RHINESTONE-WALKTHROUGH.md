## 4. Admin Panel — Scene Manager

This is the heart of the no-code admin experience.

### Reorder scenes
- Drag the grip handle on the left of any scene row to reorder.
- Changes save automatically.

### Edit a scene
- Click **Edit** on any scene row.
- Edit: title, paragraph, media type, media URL (or upload), animation type,
  procedural model (if 3D-procedural), Sketchfab embed code (if 3D-embed).
- Toggle: Set as hero (only one scene can be hero), Published.

### Generate scene text with AI
- Click **Generate with AI** next to the paragraph field.
- The Z.ai API (GLM-4.6) writes an accurate, descriptive paragraph based on
  the scene title and (optionally) the uploaded image.
- The AI tone is locked to "accurate, descriptive, factual — never poetic".

### Upload media
- Click **Upload** next to the media URL field.
- Allowed: jpg, png, webp, gif, mp4, webm, glb, gltf, mp3, wav.
- Max size: 50 MB per file.
- Files are saved to `/public/media/uploads/` and served from
  `/media/uploads/<uuid>.<ext>`.

### Sketchfab embed
- Choose media type "3D model (Sketchfab embed)".
- Paste the full `<iframe>` code from Sketchfab's "Embed" button.
- The iframe renders inline in the scene.

## 5. Admin Panel — Other Sections

### Collections
- Create, edit, delete collections (slug, name, description, cover image).
- Each collection has its own page at `/collections/[slug]`.

### Products
- Create products inside collections.
- Two pricing models:
  - **Fixed**: enter EUR price directly. Display price converts to visitor
    currency.
  - **Gold-weighted**: enter weight (g), purity (karat), making charge (EUR).
    The price is computed live as:
    `price = (weight_g × gold_rate_per_gram × purity_factor) + making_charge`
- AI button generates product description from the product name + first image.
- Stock tracking with "Only N left" warnings on the public site.

### Gallery
- Upload multiple photos at once (multi-select file picker).
- One-click AI caption button on each photo.
- Toggle published/hidden.

### Testimonials
- Add customer name, location, quote, rating (1-5 stars).
- Toggle published/hidden.

### Inquiries
- Inbox list on the left, detail view on the right.
- AI auto-routes each inquiry to: RETAIL, WHOLESALE, PRESS, APPOINTMENT, or GENERAL.
- AI drafts a reply you can edit and approve.
- "Re-run AI" button if you want a fresh route/draft.
- Mark as replied when done.

### Gold Rate
- Current cached rate per troy ounce (USD, EUR, GBP, AED, PKR).
- **Refresh from API** button — fetches live rate from goldapi.io and caches
  it in the database (overrides any previous override).
- **Override** form — enter custom values if you want to set the rate manually
  (e.g. local Irish market premium). Override is flagged with a warning chip
  in the public gold-rate ticker.

### Settings
- Brand name, tagline, SEO description.
- AI tone (locked to accurate/factual — edit cautiously).
- Background music URL (upload or paste).
- Hero video URL (the first scene of the home page).
- Logo URL (upload or paste).
- Contact: email, phone, WhatsApp, address, city, country.
- Social: Instagram, Facebook, TikTok.
- Save all changes with one button.

## 10. OpenRouter Setup (YOUR API KEY)

All AI features (the 6 automations + Rían the chatbot) now use **OpenRouter** instead of Z.ai.

### How to enable AI

1. Get an OpenRouter API key at <https://openrouter.ai/keys> (free tier available, $5 free credit on signup).
2. Paste it into the `.env` file at the project root:
   ```
   OPENROUTER_API_KEY="sk-or-v1-..."
   ```
3. Restart the dev server (or wait for Vercel to redeploy).
4. All AI features activate instantly.

### Default model

`openai/gpt-4o-mini` — picked by you. Cheap (~$0.20/1M input tokens), fast, solid for chat personality + scene text.

To switch models, edit `.env`:
```
OPENROUTER_MODEL="anthropic/claude-3.5-sonnet"
# or
OPENROUTER_MODEL="google/gemini-2.0-flash-exp:free"
# or any other model from https://openrouter.ai/models
```

The model is used for everything (chatbot + scene text + product descriptions + inquiry routing + alt text + gallery captions). If you want different models for different features, ask and I'll wire per-feature model overrides.

### What happens when the key is missing

If `OPENROUTER_API_KEY` is empty or invalid:
- **Chatbot**: Rían apologises and asks the visitor to email instead. The conversation is still saved to the admin inbox.
- **Scene text / product description / other admin AI buttons**: Show a toast error explaining the key is missing.
- **Contact form**: Still saves the inquiry; the AI routing and reply draft are skipped silently.

### What changed from the previous version

- All `z-ai-web-dev-sdk` imports removed — replaced with direct `fetch()` calls to OpenRouter's OpenAI-compatible endpoint.
- All 6 AI helpers (`generateSceneText`, `generateProductDescription`, `draftReplyWithAI`, `generateAltText`, `generateGalleryCaption`, `routeInquiryWithAI`) use the new `chat()` function.
- The chatbot uses a new `chatMultiTurn()` function for multi-message history.
- The old `ZAI_API_KEY` env var is kept in `.env` for reference but is no longer used. You can remove it.

## 10c. How to Add or Remove Videos

You asked: yes, you can add or remove videos on the site without touching code. There are two places videos are used:

### 1. Hero video (the background of the home page's first scene)

This is stored as the first scene in the **Scenes Manager**.

**To change the hero video:**
1. Go to `/admin/scenes` (admin login required).
2. Find the scene marked as the hero (the one with the gold star — usually scene 0, "Rhinestone Jewellers").
3. Click **Edit** on it.
4. Under "Media type", keep it set to **Video**.
5. Either:
   - Paste a new video URL into the "Media URL" field, OR
   - Click **Upload** to upload a new video file (.mp4, .webm — up to 50 MB).
6. Click **Save scene**. The new video goes live instantly on the home page.

### 2. Per-scene videos

Each scene in the scrollytelling can be a video. Currently scenes 0 and 1 are video backgrounds; you can make any scene a video.

**To add a video as a new scene:**
1. Go to `/admin/scenes`.
2. Click **New scene** (top right).
3. Set the title (e.g. "Behind the Workshop").
4. Set Media type to **Video**.
5. Upload your video file or paste a URL.
6. Pick an animation type (Fade / Slide up / Parallax / Zoom — try "Parallax" for video).
7. Optionally click **Generate with AI** to write the scene's paragraph.
8. Click **Save scene**. Drag the new scene to wherever you want it in the order.

**To remove a video:**
- Either delete the whole scene (Trash icon → confirm), OR
- Edit the scene and change Media type to **Text only** (no media), OR
- Edit the scene and change Media type to **Photo** / **3D model** to swap the video for a different media type, OR
- Toggle the **Published** switch off to hide the scene without deleting it.

### 3. Background music (audio, not video — but similar)

- Go to `/admin/settings`.
- Scroll to the **Media** section.
- **Background music URL**: paste a new URL or click **Upload** to upload a new audio file (.mp3, .wav — up to 50 MB).
- Click **Save all settings**.

### Notes on videos

- **Max file size**: 50 MB per upload. Larger files won't upload through the admin UI — for huge files, drop them directly into `/public/media/` on the server and reference the path (e.g. `/media/my-video.mp4`).
- **Best format**: MP4 with H.264 video + AAC audio. WebM also works.
- **Autoplay rules**: videos on the site are muted by default to comply with browser autoplay policies. The hero video loops silently.
- **For production on Vercel**: file uploads go to `/public/media/uploads/` which is ephemeral on Vercel (files don't persist across deploys). For persistent storage, wire Vercel Blob by editing `src/app/api/admin/upload/route.ts`. The current code is a single endpoint — swap the local file write for a Vercel Blob upload and everything else stays the same.

## 15. Live Chat — The Sales Bot "Rían"

A full live-chat sales bot is built into the public site. The bot is **Rían**, a 30-something Irish jeweller working at the family workshop on Grafton Street. He's not a chatbot — he's a character.

### How the chat appears

- **Floating button** at bottom-left of every public page (hidden on `/admin/*` routes).
- Click to open the chat window. Greeting: *"Hi there — I'm Rían, the jeweller here at Rhinestone. What brings you to our corner of Dublin today?"*
- Messages persist via `localStorage` so visitors can come back later and pick up where they left off.

### Personality brief (what the bot does)

Designed per your spec:

| Behaviour | How it works |
|-----------|-------------|
| **As humanly as possible** | Irish English, contractions, short messages, occasional Irish phrases ("grand", "to be fair", "having a nosy"). Never says "as an AI". |
| **Listens, gives opinions** | Asks discovery questions before recommending. Has real opinions (gold-weighted pricing > fixed; mass-market brands cut corners). |
| **Knows how to sell (cunning)** | Listens first, builds rapport, recommends from the live catalog, never pushes. |
| **Emotional conversation** | Remembers the partner's name, the wedding date, the story. Brings them back later. Congratulates genuinely at the close. |
| **Talks what they talk** | Mirrors register — formal ↔ casual, slang ↔ standard. Cracks jokes back if they crack jokes. |
| **Religious touch if required** | If the customer mentions a baptism, communion, church wedding, confirmation — Rían engages respectfully ("lovely — what parish?"). He's Irish; this is just normal conversation. He never pushes religion, but doesn't avoid it when they bring it up. |
| **Can talk irrelevantly** | Will talk about the weather, football (GAA leanings), the price of a pint, anything. Steers back when the moment is right. |
| **Creates a margin with arguments** | When pushed on price, does NOT immediately discount. Justifies with HONEST comparisons to Tiffany (machine-finished vs hand-set), Pandora (silver plate vs sterling), Cartier (40% for the name), and local Indian jewellers (different tradition, not direct competition). Discount only for serious reasons (wholesale, multi-piece, loyal return customer) and even then "thinks about it". |
| **Finalizes the deal** | Confirms the piece, the price, the shipping, asks for email. |
| **Congratulates genuinely** | Real Irish congratulations ("Ah that's a beautiful choice, Sian's going to love it — well done, you."), not "Congratulations on your purchase!". |
| **Admin sees everything** | Every message is tagged (rapport, discovery, recommendation, comparison, margin_defence, closing, congratulations, off_topic, capture). Bot writes private admin notes at each step explaining what it's doing and why. Captured name/email/phone are stored on the conversation record. |

### What the bot knows

The bot's system prompt is built fresh on every message and includes:
- **Live catalog** — every published product with its name, collection, pricing (fixed EUR or gold-weighted weight/karat/making charge), and short description.
- **Live gold rate** — current cached rate per troy ounce in all 5 currencies, plus the formula for computing gold-weighted prices.
- **Site context** — brand name, city, email.
- **Conversation history** — the last 20 messages (so Rían remembers what was said).

### How to see what the bot is doing

Visit `/admin/chat`. You'll see:
- All conversations sorted by most recent activity.
- Filter buttons: All / Open / Won / Lost.
- For each conversation:

### Customising Rían's personality

The full system prompt lives at `src/lib/chat-system-prompt.ts`. Edit it to:
- Change his name (search for "Rían")
- Tweak the personality (search for "PERSONALITY" or "HOW YOU SELL")
- Add more brand comparisons (search for "Tiffany" or "Pandora" and add yours)
- Adjust the religious-touch calibration
- Add specific phrases you want him to use or avoid

The prompt is rebuilt on every message, so changes take effect immediately on the next chat turn.

### API: chat endpoint

`POST /api/chat` with body `{ visitorId, message }`. Returns `{ reply, tag, conversationId }`.

The visitor ID is generated by the frontend (`v_<random>`) and stored in `localStorage` so conversations persist across sessions for the same browser.
